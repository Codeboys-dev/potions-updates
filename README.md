# PotionsCore playtest downloads

Download the latest launcher from the **Releases** section. Extract
`PotionsUpdater-1.0.1.zip`, then run `PotionsUpdater.exe`.

The launcher downloads, verifies, installs, and starts the latest PotionsCore
playtest build. Close PotionsCore before updating.

This repository is intentionally public so external playtesters can download
builds without a GitHub account.
